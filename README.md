# Handy Market

**Find local, trusted help at your fingertips.**

Handy Market is a web-based service marketplace designed to connect customers with local informal service providers such as handymen, cleaners, gardeners, and other service professionals.

## About the Project

Handy Market was developed to make it easier for customers to find and book local service providers while giving small and informal service providers a platform to advertise their services.

The system focuses on simplicity, accessibility, and trust between customers and service providers.

## Features

* Customer registration and login
* Service provider registration and profiles
* Service searching and browsing
* Provider verification
* Service bookings
* Booking status management
* Customer and provider dashboards
* Messaging functionality
* Admin management
* User and service management
* Payment status tracking
* Responsive web interface

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* Bootstrap

## User Roles

### Customer

Customers can:

* Create an account
* Browse available services
* View service providers
* Make bookings
* Track booking status
* Communicate with providers

### Service Provider

Providers can:

* Create a service profile
* Add their services
* Manage bookings
* Update booking statuses
* Communicate with customers

### Administrator

Administrators can:

* Manage users
* Verify service providers
* Manage services
* Manage bookings
* Monitor the platform

## Project Purpose

The purpose of Handy Market is to provide a simple digital platform for connecting customers with local service providers and supporting informal businesses.
